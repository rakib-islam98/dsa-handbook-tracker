# 🚀 DSA Tracker

A simple, fast, and privacy-focused web application to help you stay consistent with Data Structures & Algorithms practice.

Track your progress, follow a structured roadmap, maintain practice streaks, take notes, and organize your DSA journey—all without creating an account.

---

## ✨ Features

### 📚 Structured DSA Roadmap
- Topic-wise learning roadmap
- Beginner to advanced progression
- Organized by patterns and concepts
- Easy navigation between topics

### ✅ Progress Tracking
- Mark topics as completed
- Track solved problems
- Monitor overall progress
- Resume exactly where you left off

### 🔥 Practice Streak
- Daily practice streak counter
- Helps maintain consistency
- Encourages regular problem solving

### 📝 Personal Notes
- Save topic-wise notes
- Record important observations
- Store revision points
- Edit anytime

### 📊 Statistics Dashboard
- Overall completion percentage
- Problems solved
- Remaining topics
- Practice insights

### 💾 Local Storage
- Works completely in your browser
- No account required
- No server-side data storage
- Fast loading

### ☁ Optional Cloud Backup
- Backup your progress manually
- Restore data anytime
- Prevent accidental data loss

---

# 📌 Why This Project?

Learning DSA becomes difficult when there is:

- No structured roadmap
- No progress tracking
- No revision notes
- No consistency
- No motivation to continue

DSA Tracker solves these problems by keeping everything organized in one place.

# 💾 Data Storage

This application stores your progress locally in your browser using **Local Storage**.
Your data never leaves your device unless you explicitly export or back it up.

---

# ⚠ Important Notice

This application **does not use any server or database**.
Your progress is stored only inside your browser.

If you:

- Clear browser data
- Clear site storage
- Reset the browser
- Reinstall the browser

your progress **will be permanently lost** unless you have created a backup.
It is strongly recommended to export or back up your progress regularly.
