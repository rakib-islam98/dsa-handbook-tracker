Privacy Policy

Last updated: October 2026

DSA Handbook Tracker ("the application", "we", "us", or "our") is a client-side web application designed to help users organize and track their Data Structures and Algorithms learning progress.

1. Information Stored by the Application

DSA Handbook Tracker stores user-generated information such as solved-problem status, practice progress, notes, checkpoints, streak information, and application preferences.

This information is primarily stored locally in the user's web browser using browser storage technologies such as localStorage.

2. Local Backup

The application provides an option to export application data as a backup file. Users can also import a previously exported backup file to restore their data.

These backups are initiated by the user and are not automatically uploaded to our servers.

3. Google Sign-In

The application optionally allows users to sign in using their Google account.

Google authentication is used to identify the user's Google account and enable the optional Google Drive backup functionality.

4. Google Drive Backup

If a user chooses to use Google Drive backup, the application requests access to Google's application-specific storage area using the following OAuth scope:

https://www.googleapis.com/auth/drive.appdata

This permission allows the application to create, access, update, and delete its own application-specific backup data in the user's Google Drive.

Google Drive backup is optional and is only used when the user chooses to connect their Google account and use the backup feature.

5. Google Information We Access

Depending on the authentication flow, the application may receive basic Google account information such as the user's email address, profile information, and account identifier required for authentication.

The application does not request access to the contents of Gmail messages, Google Photos, Google Contacts, or unrelated files in the user's Google Drive.

6. How Google Data Is Used

Google account information is used only to authenticate the user and provide the optional Google Drive backup functionality.

Application backup data is used only to allow the user to back up and restore their DSA Handbook Tracker information.

7. Data Sharing

We do not sell, rent, or intentionally share users' personal information with third parties for advertising or marketing purposes.

8. Data Storage and Retention

Locally stored application data remains in the user's browser until it is removed by the user or by browser storage management.

Google Drive backup data remains in the user's Google Drive according to the user's actions and Google Drive's policies.

9. Third-Party Services

The application may use third-party services and libraries, including Google authentication and Google Drive APIs, content delivery networks, and hosting services.

Their respective privacy policies and terms may apply to information processed by those services.

10. User Control

Users can choose whether or not to use Google Drive backup. Users can also remove locally stored application data through their browser's storage controls and manage their Google account permissions through their Google Account settings.

11. Security

Reasonable measures are taken to protect the application and its functionality. However, no web application or internet transmission can be guaranteed to be completely secure.

12. Changes to This Privacy Policy

This Privacy Policy may be updated when the application, its functionality, or its data practices change. Any updated version will be published on this page.
